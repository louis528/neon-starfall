**Neon Starfall** is a neon arcade space shooter that runs entirely in the browser — no build step, no assets, no network: every ship is drawn in code on a canvas and every sound is synthesized with WebAudio.

Pilot your starfighter through endless waves: sine-diving drones, spinning asteroids, and a carrier with a health bar every fifth wave that answers with aimed burst fire. Chain kills to raise the combo multiplier, and catch what the wreckage drops — spread shot, a shield bubble, and the rare extra life.

- **Move:** WASD, arrow keys, or drag · **Fire:** hold Space or hold the pointer · **Pause:** P · **Mute:** M
- Title, wave banners, pause and game-over screens; best score kept between visits
- Parallax starfield and nebula, particle explosions, muzzle flash, screen shake and hit-flash — all procedural

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 — or hand it in the way the grader does:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
